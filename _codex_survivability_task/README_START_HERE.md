# Как передать Codex задание на EHP и лечение

В архиве содержатся:

- `CODEX_SURVIVABILITY_MASTER_PROMPT.md` — полное техническое задание на русском, **11 503 слова** по разбиению пробелами (размер не искусственно дополнен до 20 тыс.).
- `REFERENCE_CASES.json` — проверочные значения со скриншотов пользователя.
- `evidence/01_centurion_full_result.png` — сборка с «Центурионом», весь результат.
- `evidence/02_centurion_ehp_tooltip.png` — подсказка EHP.
- `evidence/03_centurion_healing_tooltip.png` — подсказка лечения 3,24.
- `evidence/04_without_armor_healing_tooltip.png` — тот же видимый состав без брони; 1,53.

## Вариант А: поместить в репозиторий

Распакуйте весь пакет в папку с проектом, например:

`C:\myprofrma\stalzonesborka-agent\_codex_survivability_task\`

В новой сессии Codex в директории проекта вставьте:

> Прочитай полностью файл `_codex_survivability_task/CODEX_SURVIVABILITY_MASTER_PROMPT.md`, затем четыре скриншота из `_codex_survivability_task/evidence/` и `REFERENCE_CASES.json`. Это основное техническое задание; следуй фазам, безопасности и Gate из файла. Не сокращай выполнение до косметического UI-патча. Начинай с Phase 0, рабочую БД и сервер не трогай. Отчёт сохрани по указанному в документе пути.

## Вариант Б: хранить пакет отдельно

Распакуйте архив в произвольную доступную Codex директорию и сообщите Codex **абсолютный путь** к `CODEX_SURVIVABILITY_MASTER_PROMPT.md` и `evidence/`. Скриншоты не входят в один `.md`, поэтому при варианте без архива нужны отдельные изображения.

## Проверяемые факты

С «Центурионом» `EHP=647.32`, `Лечение=0.50%`, tooltip `3.24 HP/с`. Без брони `EHP=305.97`, `Лечение=0.50%`, tooltip `1.53 HP/с`. Выражение `EHP × 0.005` согласуется с обеими подсказками после округления, но полная универсальная формула и зависимость самого процента лечения от бонусов **не доказаны**.

## Защита проекта

Не запускать `/finalize.py` из старых исследований. Не выполнять `git reset/clean/checkout`, commit, push, deploy, production server restart или live market refresh. Допустим только условный перенос после GO, с точным backup и проверенным откатом своих изменений.
