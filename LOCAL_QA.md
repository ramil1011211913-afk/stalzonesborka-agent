# Локальная проверка приложения

Дважды запустите `local_qa.bat`. Проверка выполняется на этом компьютере; Codex для её работы не нужен. Потребуются Python 3.12, установленные зависимости проекта и `psutil`. Для проверки интерфейса дополнительно нужны пакет `playwright` и Google Chrome. Если Playwright не установлен, проверка интерфейса будет отмечена как пропущенная.

Скрипт сохраняет согласованный снимок `data/stalzone.db`, запускает отдельный сервер на свободном локальном порту, отключает на нём обновление аукциона и завершает сервер после тестов. Рабочий сервер на порту 8123 не используется. Отчёт `report.json`, копия базы, лог сервера и снимок интерфейса сохраняются в новой папке `data/local_qa/`.

По умолчанию выполняются три волны по 100 запросов, до 32 одновременно, пять сценариев поиска, 16 повторных поисков с замерами ресурсов и один сценарий интерфейса. Это нагрузочные запросы, а не полноценная симуляция 100 людей; краткий прогон не доказывает отсутствие медленных утечек или глобального оптимума.

Из PowerShell, находясь в папке проекта:

```powershell
py -3.12 tools\local_qa.py
py -3.12 tools\local_qa.py --full
py -3.12 tools\local_qa.py --requests 200 --waves 5 --workers 32 --searches 30
```

`--full` дополнительно запускает весь набор pytest на отдельной копии кода и базы и сохраняет `pytest.log`. Можно использовать `--skip-ui` или `--skip-search`; `--searches 0` отключает повторные поиски ресурсов. Проверки выполняются последовательно, поэтому длительность зависит от скорости компьютера и выбранных лимитов поиска.

Если необходимый пакет отсутствует, установите его в Python 3.12 через `py -3.12 -m pip install psutil playwright pytest`; зависимости самого приложения перечислены в `requirements.txt`. Если Chrome недоступен, используйте `--skip-ui`.
