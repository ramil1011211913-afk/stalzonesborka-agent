## 9. Численные сертификаты и интервалы

SciPy **1.18.1**, встроенный HiGHS **1.12.0**, Python 3.12.7. Максимизируется `sum(sprint_i*x_i)+constant`; минимизируемая цель — её отрицательная переменная часть. Поэтому `UB_sprint=-mip_dual_bound+constant`; для исходного rgoz constant=0. Для цены в миллионах `LB_price=mip_dual_bound*1 000 000`. Все исходные status/message, nodes, native objective, bound, gap, ограничения и матрицы сохранены, знак проверен на самом objective. Семантика границы и gap — по [SciPy milp](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html).

Основные строгие A/B завершены status=0, relative gap=0 при `mip_rel_gap=0`, `mip_abs_gap=1e-10`, `mip_feasibility_tolerance=1e-9`, primal/dual feasibility=1e-9. Дополнительные параметры переданы HiGHS через документированное forwarding SciPy; его warning об unrecognized options сохранён, это не ошибка solver. Значения по умолчанию дополнительно считаны из установленного `HighsOptions`, а не предположены по другой версии; [справочник HiGHS](https://ergo-code.github.io/HiGHS/dev/options/definitions/) поясняет смысл допусков.

Практический численный результат — **примерно 14,751669%**, устойчивый в выполненных строгих/обычных запусках.
